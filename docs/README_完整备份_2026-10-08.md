# Aperture-Diffraction

普通物理学实验 II —— 光阑衍射的深度学习探究

> 用「可微的物理模型 + 神经网络」去学习**光阑形状 ↔ 衍射图样**之间的双向映射。

---

## 0. 项目总目标与当前进度

整个实验分三个阶段，本仓库目前处于**第一阶段（已完成）**。

| 阶段 | 目标 | 关键方法 | 状态 |
|------|------|----------|------|
| 一 | 训练**正向**网络：输入光阑形状，输出衍射图样，保证高准确率 | 物理引导残差学习（可微 FFT 物理层 + 残差 U-Net） | ✅ 已完成 |
| 二 | 训练**逆向**网络：输入衍射图样，输出光阑形状 | 逆网络 + 正向网络闭环（循环一致性损失） | ⏳ 待开展 |

## 1. 实现目的

衍射是波动光学的核心现象：**一个光阑形状决定了它远场的衍射图样**。经典做法是用傅里叶变换解析计算，但真实场景中往往希望反过来——**只看衍射图样，推断是什么形状的光阑**。这正是「相位恢复 / 逆散射」类问题的核心难点。

本实验的目的：

1. **第一阶段**：构建一个"光阑 → 衍射图样"的正向预测网络，并验证**引入物理先验**相比纯数据驱动网络的优势。核心命题是：当物理规律已知时，把它写进网络，可以让网络学得更准、更省、更稳。
2. **第二阶段**：构建"衍射图样 → 光阑"的逆向网络。逆问题是**病态、多解**的，因此不能只做监督学习，而要把第一阶段的正向网络当作**可微的约束**，让逆网络的输出再送回正向网络，比较重建结果与原输入的 loss，从而反向传播校正逆网络权重（闭环 / 循环一致性训练）。
3. **第三阶段**：把正、逆网络组合成一个完整的双向预测系统，并在**不同数据集**以及**存在外界干扰（例如毛玻璃）**的条件下验证鲁棒性，目标是干扰下误差尽量小。

面向物理实验教学，本仓库同时提供了可复现的数据生成、训练、评估与对比脚本，便于观察"物理 + 学习"到底带来了什么。

## 2. 理论知识

### 2.1 标量衍射与夫琅禾费近似

设光阑的复振幅透过率为 $a(x,y)$。在**远场（夫琅禾费）条件**下

$$
z \gg \frac{a_{\max}^2}{\lambda},
$$

衍射场的复振幅正比于光阑函数的二维傅里叶变换，观察面上的**光强**为

$$
I(u,v) \;=\; \bigl|\,\mathcal{F}\{a(x,y)\}\,\bigr|^{2},
$$

其中 $\mathcal{F}\{\cdot\}$ 为二维傅里叶变换，$(u,v)$ 为与观察面坐标线性对应的空间频率。

由此可得几个定性结论（也是本实验数据正确性的判据）：

- **圆孔** → 中央艾里斑 + 同心弱环（Airy pattern）；
- **单缝 / 多缝** → 沿垂直于缝方向的 sinc 包络 + 干涉条纹；
- **光栅** → 分立的高级次衍射斑；
- **孔洞阵列** → 阵列因子 × 单孔因子的乘积结构（稀疏化 → 干涉尖峰）。

尺寸与图样的关系是**反比**的：光阑越大，衍射图样越集中；光阑越小，衍射越"铺开"。这正是逆问题多解性的来源。

### 2.2 数值离散与 FFT

把光阑离散为 $N\times N$ 网格（本项目 $N=256$），离散化后上式用 FFT 实现：

```python
field_f   = fftshift(fft2(aperture))
intensity = |field_f| ** 2
```

`fftshift` 把零频搬到图像中心，与光学观察面的直观坐标一致。

### 2.3 动态范围与对数压缩

衍射图样的动态范围极大（中心峰可比旁瓣亮 $10^3\sim10^6$ 倍）。若直接回归线性强度，loss 会被中心峰主导，旁瓣（承载形状信息的关键结构）几乎学不到。因此对强度做**对数压缩**：

$$
I_{\text{log}} = \frac{\log\!\bigl(1+\alpha\,I_{\text{norm}}\bigr)}{\max_{u,v}\,\log\!\bigl(1+\alpha\,I_{\text{norm}}\bigr)},\qquad \alpha = 100 .
$$

它既模拟了探测器/成像的压缩响应，也让中心峰与旁瓣在数值上量级接近，便于网络均衡学习。生成数据与训练中的物理层**必须使用完全相同的后处理**，否则会出现"物理层输出与标签不匹配"的伪误差。

### 2.4 物理引导神经网络（Physics-Guided Learning）

本项目的正向模型不是"让 CNN 从零去逼近 FFT"，而是把**已知的物理当成一个无参数、可微的算子层**直接嵌入网络：

$$
\hat{I} \;=\; \underbrace{\Phi_{\text{phys}}(a)}_{\text{FFT 物理层}} \;+\; \underbrace{R_\theta\bigl(a,\ \Phi_{\text{phys}}(a)\bigr)}_{\text{残差网络}} .
$$

思想来自残差学习（ResNet）与物理信息神经网络（PINN/Physics-Informed）：

- 物理层已经给出"主项"，网络只需学习**残差修正项** $\Delta I$；
- 残差网络输出层**零初始化**，训练起点就是 $\hat I = \Phi_{\text{phys}}(a)$，从"纯物理"开始，逐步叠加学到的修正；
- 物理层无参数、不占用学习容量，天然保证输出满足衍射规律（可解释、可泛化）。

### 2.5 逆问题的数学本质（为第二、三阶段铺垫）

逆问题 $a \mapsto \hat I$ 的求逆是**相位恢复（phase retrieval）**：衍射测量只给了强度 $|\mathcal F a|^2$，**丢失了相位**。存在大量不同光阑给出（几乎）相同强度图样的情形，因此逆问题是**非线性、非凸、多解的**，必须引入先验才能稳定求解。

本项目采用的策略是**闭环（循环一致性, cycle-consistency）训练**：

$$
\text{Loss} = \mathcal{L}\Bigl(\underbrace{\Phi_{\text{phys}}\bigl(G_\phi(I)\bigr)}_{\text{逆网络输出再走一遍正向}},\ I\Bigr),
$$

即让逆网络 $G_\phi$ 的输出经过（已知的、冻结或联合训练的）正向网络，重建出原衍射图样，用重建误差反向传播来校正 $G_\phi$。这与自编码器、CycleGAN 里的循环一致性约束同源，是第三阶段"双向网络"的理论基础。

## 3. 实现逻辑

### 3.1 数据流水线（`generate_data.py`）

1. **随机光阑生成**：内置 8 种策略，覆盖不同几何结构，保证数据多样性。

   | 策略 | 内容 |
   |------|------|
   | `multi_elements` | 多个不同元素（矩形/圆/椭圆/多边形）随机摆放 |
   | `slits` | 单缝/多缝，随机缝宽、缝距、倾角 |
   | `grating` | 有限尺寸光栅（随机周期、占空比、角度） |
   | `hole_array` | 孔洞阵列（网格 / 环形 / 随机） |
   | `letter` | 字母形状（T/L/H/X/O/C/F/E） |
   | `annular` | 环形 / 多环 / 扇形 |
   | `mixed_grating` | 光栅 + 缺陷 + 附加圆孔 |
   | `polygons` | 正多边形 / 不规则多边形 / 星形 / 十字 / 多个三角 |

2. **物理模拟** `simulate_diffraction()`：与训练中的物理层逐行对齐——
   `FFT → fftshift → |·|² → 归一化 → log(1+α·I) → 再归一化`。
3. **噪声与透过率扰动**：乘性透过率 $[0.85,1.0]$、加性高斯噪声 $\sigma = 0.005$，再 clip 到 $[0,1]$，避免数据集过于"干净"。
4. **输出**：`data/apertures.npy`、`data/patterns.npy`（$(N,256,256)$ float32），以及若干预览图。

关键超参数：`GRID=256`、`N_SAMPLES=5000`、`SEED=42`、`LOG_ALPHA=100.0`、`APERTURE_NOISE=0.005`。

### 3.2 正向模型（`train.py`）

```
光阑 a ──► FraunhoferLayer(可微, 无参数) ──► I_sim
   │                                            │
   └──────────────┐                             │
                  ▼                             ▼
            ResidualUNet(a, I_sim) ──► ΔI ──► Î = I_sim + ΔI
```

- **`FraunhoferLayer`**：纯 FFT + log 压缩，无参数、完全可微，与数据生成严格一致。
- **`ResidualUNet`**：轻量 U-Net（`base_ch=32`），输入 2 通道 `concat(a, I_sim)`，输出单通道残差；下采样-上采样 + 跳跃连接；**输出层权重与偏置零初始化**，保证训练从"纯物理"出发。
- **`PhysicsGuidedModel`**：串联上述两层，前向同时返回 `(I_pred, I_sim, ΔI)`，便于在 loss 中分别约束。

### 3.3 损失函数（`train.py::Loss`）

$$
\mathcal{L} = \underbrace{\|Î - I\|_1}_{\text{空间 L1}}
 + \lambda_f \underbrace{\bigl\|\log(1+|FÎ|)-\log(1+|FI|)\bigr\|_1}_{\text{频域 log 幅度}}
 + \lambda_s \underbrace{(1-\text{SSIM}(Î,I))}_{\text{结构}}
 + \lambda_r \underbrace{\|ΔI\|_1}_{\text{残差正则}} .
$$

- **空间 L1**：主约束；
- **频域 log 幅度**：对旁瓣/级次等高频细节更敏感，避免被中心峰掩盖；
- **SSIM**：约束几何结构（艾里环、光栅级次）；
- **残差 L1 正则**：鼓励残差接近 0，防止网络"重学"物理层已算好的部分；
- $\lambda_f=0.1,\ \lambda_s=0.2,\ \lambda_r=10^{-3}$，各项均可单独关闭以做消融。

（SSIM 通过 `torchmetrics` 或 `pytorch-msssim` 提供，未安装时自动置 0，不影响其余项。）

### 3.4 训练策略

- 优化器 AdamW（`lr=1e-3`, `weight_decay=1e-4`），余弦退火 `CosineAnnealingLR`；
- `epochs=50`, `batch_size=32`, 验证集占 10%，梯度裁剪 `clip_grad_norm_=1.0`；
- 按验证集 L1 保存最优权重到 `best_model.pt`；
- **训练前自检**：用第 0 个样本比较物理层输出与标签的 MAE 与相关系数，若不匹配（MAE<1e-3 且 Corr>0.999 视为通过）则直接报错，防止"物理层与数据不一致"的隐蔽 bug。

### 3.5 基线对比（`baseline.py`）

为了回答"物理先验到底有没有用"，实现了 `PureUNet`——**与残差网络完全相同的骨干结构**（参数量仅差 288 个，<0.02%），唯一区别是**没有 FFT 物理层**，端到端直接从光阑预测衍射图样。为公平，基线单独调参：`lr=3e-4`，输出层线性且 `bias=target_mean` 初始化（避免 sigmoid 在均值≈0.05 处饱和），并关闭 SSIM 与残差正则。

### 3.6 评估（`evaluate.py`）

指标：`MAE / MSE / RMSE / PSNR / 相对误差 / 相关系数 / 峰值位置误差`。可视化：样本对比、误差热图、误差直方图，以及**极端测试**（单缝、双缝、圆孔、方孔、光栅、全通、全挡、单点）与**参数扫描**（缝宽、圆孔半径、光栅周期）。

## 5. 实现结果

### 5.1 定量指标（验证集 500 个样本）

来自 `comparison/metrics.txt`：

| 模型 | MAE ↓ | RMSE ↓ | PSNR ↑ | Corr ↑ |
|------|-------|--------|--------|--------|
| Physics only（纯物理，无网络） | 0.000000 | 0.000000 | 172.71 | 1.00000 |
| Baseline PureUNet（纯数据驱动） | 0.002694 | 0.024177 | 33.74 | 0.00572 |
| **Physics + Residual（本项目）** | **0.000000** | **0.000000** | 144.51 | 1.00000 |

相对基线的最优 MAE 改善：**+100%**（物理引导模型把误差压到数值精度级别，而纯数据驱动基线误差高出数百倍）。

> 进一步的**跨届对比**（今年物理引导 vs 去年队伍 pix2pix）见 **第 7 节**。

### 5.2 结论与解读

1. **物理先验极其有效。** 纯 U-Net 在同等容量、同等数据下，相关系数仅 **0.0057**（几乎等于在输出常数均值），而物理引导模型的相关系数为 **1.0**。这说明"光阑 → 衍射图样"的映射若交给网络从零学习，在 5000 样本规模下几乎学不动；把 FFT 作为可微层嵌入后，问题被化简为"学习一个接近 0 的残差"。
2. **残差网络确实退化为近似恒等映射。** 训练日志与可视化显示残差 $\Delta I \approx 0$，即网络发现物理层已经足够好，无需额外修正——这与"输出层零初始化 + 残差正则"的设计预期一致。
3. **⚠️ 一个必须指出的偏差。** `eval_results/metrics.txt` 里出现了 `Improvement: -37057%` 这类异常数值，原因是：数据生成与物理层**在数学上完全相同**，导致物理层输出与标签的 MAE 已到 $10^{-7}$ 量级，分母趋近于 0 时**百分比改善指标数值失稳**。因此该百分比不应作为结论，应以 MAE / PSNR / Corr 为准。
4. **由此暴露的局限（也解释了为什么需要第二、三阶段）：** 当前正向任务几乎等价于"FFT + 恒等"，任务本身过于理想化，无法真正检验泛化能力。真正有挑战性的场景是**逆问题**与**存在外界干扰**的情形——那时物理层与真实测量不再完全一致，残差网络才有实际可学的空间。

### 5.4 训练过程图解读

#### 图 1 · `train_result.png` —— 正向模型预测总览

#### 图 2 · `loss_curve.png` —— 正向模型多分量损失曲线

![正向模型损失曲线（L1 / 频域 / SSIM / 残差正则）](loss_curve.png)

由 `train.py::plot_loss_curve()` 生成，横轴为 epoch，蓝线 train、橙线 val，纵轴取对数，最多 4 个子图：

1. **L1 loss**：空间域主损失，训练/验证同步快速下降并收敛，说明拟合有效且未明显过拟合；
2. **Freq log-magnitude L1**：频域 $\log(1+|F\hat I|)$ 与真值的差，刻画旁瓣、级次等高频结构是否学对；
3. **SSIM loss $(1-\text{SSIM})$**：结构相似度损失，衡量几何结构（艾里环、光栅级次）的一致性；
4. **Residual regularization $|\Delta I|$**：残差幅度正则项，稳定在极小值，对应"残差≈0"。

## 6. 专题对比：有物理层 vs 无物理层

这一节专门回答一个问题：**同样是 U-Net，为什么"插一层物理"与"不插物理"差别会这么大？** 我们从原理、损失函数、实现方式到实测效果做逐项对比，并解释物理层"没有参数"这一特性，以及它到底可不可微（这里有一个常见误解需要澄清）。

### 6.1 两种范式

```
# 无物理层（纯数据驱动, baseline.py::PureUNet）
光阑 a ──► CNN f_θ ──► Î                       # 网络要自己学会整个变换

# 有物理层（物理引导, train.py::PhysicsGuidedModel）
光阑 a ──► Φ_phys (FFT, 固定) ──► I_sim
  │                                   │
  └────────────► R_θ(a, I_sim) ──► ΔI ──► Î = I_sim + ΔI
```

- **无物理层**：$\hat I = f_\theta(a)$，一切从数据学，网络必须**隐式地重新发明**一个二维傅里叶变换。
- **有物理层**：$\hat I = \Phi_{\text{phys}}(a) + \Delta I$，物理规律已知，网络只负责学习**偏差（残差）**。

### 6.2 原理：为什么纯 CNN 很难学 FFT

关键在于**算子的结构不匹配**：

1. **傅里叶变换是全局算子。** FFT 的每一个输出像素都依赖**全部**输入像素（权重是复指数 $e^{-i2\pi(ux+vy)}$），属于"全图耦合"。
2. **卷积是局部算子。** CNN 的卷积核只覆盖一个小邻域，要"拼"出一个全局耦合算子，必须堆叠大量层 + 池化，把感受野慢慢扩大。
3. **频率域的精细结构极易被抹平。** 衍射图样的旁瓣、级次这些高频细节，正是形状信息所在；纯卷积在有限深度下很难同时抓住中心峰与弱旁瓣。
4. **样本效率极低。** 重新学一个已知的确定性变换，等于浪费模型容量与数据；5000 个样本远远不够。

物理层做的事，本质上是提供一个**强归纳偏置（inductive bias）**：把"绝对正确、无需学习"的部分固化下来，问题从"学整个 FFT"降维成"学一个小残差"。

### 6.3 损失函数：两者用法不同

两个模型共用同一套 `Loss` 类，但**启用的项不同**，这不是随意选择，而是由模型结构决定的。

| 损失项 | 含义 | 有物理层 | 无物理层（baseline） |
|--------|------|:--------:|:--------------------:|
| 空间 L1 $\;\|Î-I\|_1$ | 主拟合约束 | ✅ $\lambda=1$ | ✅ $\lambda=1$ |
| 频域 log 幅度 L1 | 约束旁瓣/级次等高频细节 | ✅ $\lambda_f=0.1$ | ✅ $\lambda_f=0.1$ |
| SSIM $\;1-\text{SSIM}$ | 约束几何结构 | ✅ $\lambda_s=0.2$ | ❌ **关闭** ($\lambda_s=0$) |
| 残差正则 $\;\|\Delta I\|_1$ | 鼓励残差接近 0 | ✅ $\lambda_r=10^{-3}$ | ❌ **关闭**（无 $\Delta I$ 可约束） |

为什么 baseline 要关掉后两项（见 `baseline.py` 注释）：

- **残差正则**对 baseline 无意义——它没有 $I_{\text{sim}}$ 与 $\Delta I$ 的概念，是端到端直接输出。
- **SSIM** 在 baseline 上会与 L1 目标冲突并**主导梯度**，因此在基线对比中显式置 0，保证两条曲线只看同一套 L1/频域指标，比较才公平。

### 6.4 实现方式：代码级差异

| 维度 | 无物理层 `PureUNet` | 有物理层 `PhysicsGuidedModel` |
|------|--------------------|-------------------------------|
| 骨干结构 | U-Net (`base_ch=32`) | **完全相同**的 U-Net (`base_ch=32`) |
| 输入通道 | 1（光阑） | 2（`concat(a, I_sim)`） |
| 是否含 FFT 层 | ❌ 无 | ✅ `FraunhoferLayer`（无参数、可微） |
| 输出层初始化 | 线性输出，权重 $\sim\mathcal N(0,10^{-3})$，`bias = target_mean` | **零初始化**（权重与偏置全 0） |
| 训练起点 | 输出≈常数均值，$L_1\approx0.05$ | 输出 = 纯物理，$L_1\approx10^{-7}$ |
| 学习率 | $3\times10^{-4}$（起点差，大 LR 会发散） | $10^{-3}$ |
| 参数量 | ≈7.7 M | ≈7.7 M（仅差 288 个，<0.02%） |

> 设计上的关键巧思：**两者参数量几乎一致**，因此"有/无物理层"的效果差异，可以干净地归因于**物理先验本身**，而不是模型容量。

### 6.5 效果对比（验证集 500 样本，实测）

| 指标 | 无物理层 PureUNet | 有物理层 Physics + Residual |
|------|:----------------:|:---------------------------:|
| MAE ↓ | 0.002694 | **0.000000** |
| RMSE ↓ | 0.024177 | **0.000000** |
| PSNR ↑ | 33.74 | **144.51** |
| Corr ↑ | 0.00572 | **1.00000** |

解读：

1. **纯 CNN 基本"没学会"。** 相关系数仅 0.0057，意味着输出与真值**几乎不相关**——网络退化成输出一个接近常数均值的结果，MAE 停在 0.0027 附近下不去。
2. **物理引导模型几乎精确。** Corr = 1.0，误差到数值精度级别。因为物理层已给出主项，残差网络只需输出 ≈0 即可。
3. **残差确实退化为恒等映射。** 这正是"零初始化 + 残差正则"的预期结果：网络发现无需修正物理层。换个角度看，第一阶段的任务被物理层"解掉"了大部分，这也解释了为什么第二、三阶段（逆问题、毛玻璃干扰）才真正有挑战。

> 对应的可视化对比图见 **5.6 节（图 11–13）**：`side_by_side.png` 直观展示两模型的并排差异，`mae_distribution.png` 与 `per_sample.png` 从统计与逐样本两个角度佐证上述结论。

### 6.6 深度问答：物理层为什么"没有参数"？它到底可不可微？

这段专门澄清一个极易混淆的点。

**(1) "没有参数"指的是没有可学习的权重。**

`FraunhoferLayer` 内部只做 `fft2`、`fftshift`、`|·|²`、归一化、`log1p`——全是**由物理定律确定的数学运算**，没有任何 `nn.Conv2d` / `nn.Linear` / `nn.Parameter`。所以

```python
sum(p.numel() for p in model.physics.parameters())  # == 0
```

它扮演的是"一个写死的层"，等价于把物理定律直接搬进计算图，而不是一个待训练的模块。

**(2) "没有参数"不等于"不可微"——恰恰相反，物理层是完全可微的。**

这是最常见的误解。真相是：**无参数 ≠ 不可微**。物理层没有东西需要"训练"（没有梯度要更新任何权重），但它**仍然是可微的**，梯度可以顺畅地穿过它：

- **FFT 是线性算子**，其导数即自身（对实数输入，$\partial\,\mathrm{FFT}/\partial a$ 由复指数核给出），PyTorch 的 `torch.fft.fft2` 原生支持 autograd；
- **$|z|^2 = z\bar z$** 对实部/虚部可导（$z=0$ 处的不可导点用 `+1e-12` 平滑规避）；
- **`log1p`、除以最大值归一化**都是可导初等函数。

因此 `loss.backward()` 时，梯度会**穿过物理层**，回传到残差网络，甚至回传到光阑输入——这正是第二阶段闭环训练的基石：逆网络 $G_\phi$ 的更新，靠的就是让重建结果**穿过这个可微的正向物理层**再算 loss。

代码里的 `freeze_physics()` 把 `requires_grad` 设为 `False`，只是为省算力；由于物理层本就没有参数，设与不设**都不影响数值结果**，也不会破坏梯度通路。

**(3) 那什么情况下物理层才真的"不可微"？**

只有当物理过程里含**离散或硬决策**运算时，才会真正阻断梯度，例如：

| 不可微操作 | 场景 | 常用处理 |
|-----------|------|----------|
| 硬阈值 / 二值化 (`x > 0.5`, `sign`) | 光阑二值化、探测器触发 | 用 `sigmoid` 软松弛代替 |
| `argmax` / 取整 / 排序 | 取主峰位置、级次索引 | 直通估计器 (STE) / Gumbel-Softmax |
| 泊松采样 / 量化 | 光子计数、ADC 量化 | 重参数化 / 噪声可微化 |

本项目的物理层（FFT + 平方 + 归一化 + log）**全部是可微运算**，因此不受此限制。

**(4) "无参数"为什么反而是优点？**

| 特性 | 带来的好处 |
|------|-----------|
| 不占用模型容量 | 网络把容量全用在真正需要学的残差上 |
| 不引入与物理不符的自由度 | 输出天然满足衍射规律，**可解释、可外推** |
| 固定且精确 | 训练更稳，起点就在正确解附近，收敛快 |
| 无参数却可微 | 既能当"硬约束"用，又能参与闭环反向传播（第二、三阶段） |

一句话总结：**物理层是"零参数但要参与反向传播"的算子**——它不学习，但它可微，因而同时提供了"正确的先验"与"可训练的梯度通路"。

|------|------|
| 生成器 `Pix2PixGenerator` | U-Net：6 次下采样（$3\to64\to128\to256\to512\to512\to512$）+ 5 次上采样（带跳跃连接，前两层含 Dropout 0.5）+ 转置卷积输出，`tanh` 激活 |
| 判别器 `Pix2PixDiscriminator` | PatchGAN：输入 `concat(光阑, 衍射)` 共 6 通道，4 次下采样后接 $1$ 通道输出 |
| 通道适配 | `to_3ch`：单通道 $[0,1]$ → 三通道 $[-1,1]$；`from_3ch`：取首通道还原到 $[0,1]$ |
| 损失 | 对抗损失（`BCEWithLogitsLoss`）+ $100\times$ L1 |
| 优化 | Adam，`lr=2e-4`，`betas=(0.5,0.999)`，`batch_size=8`，30 epochs |

两者最本质的区别：**pix2pix 完全靠数据学习"光阑 → 衍射"这个全局算子，没有任何物理先验**；今年则把这个已知算子直接固化进网络。

## 8. 后续阶段规划（二、三）

**第二阶段 —— 逆网络（衍射图样 → 光阑）**

- 搭建逆网络 $G_\phi$（可复用 U-Net 骨干，输入 1 通道衍射图样，输出 1 通道光阑）；
- 闭环训练：$\hat I = \Phi_{\text{phys}}(G_\phi(I))$，用 $\mathcal L(\hat I, I)$ 反向传播校正 $G_\phi$（正向网络冻结或联合微调）；
- 引入额外先验/正则（光阑二值化、总变差、稀疏性）以缓解相位恢复的多解问题；
- 评价：光阑重建的 IoU / 像素准确率 / 边缘匹配，以及"重建光阑再正向衍射"的一致性误差。

**第三阶段 —— 双向系统与鲁棒性**

- 将正、逆网络联合成一个双向系统，联合优化；
- 在**不同数据集**上训练/测试，考察跨集泛化；
- 建模**外界干扰**：毛玻璃 → 随机相位屏 / 空间变化的点扩散函数 / 散斑；配合域随机化（随机相位、模糊核、噪声、曝光）进行增广；
- 目标：在干扰条件下仍保持低误差，并给出"有干扰 vs 无干扰"的鲁棒性对比实验。
