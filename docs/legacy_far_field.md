# 早期远场实验与本次进度的区别

最初阅读README时，项目主要由根目录四个脚本组成：`generate_data.py`、`train.py`、`baseline.py`、`evaluate.py`。正向模型采用固定夫琅禾费FFT物理层与残差U-Net，尚未开展多距离传播和角谱换层对照。

当前仓库已建立`.git`；本文写于整理前，依据早期文档、现有代码和保存结果对照，不声称对应某个远端commit。更新前完整README已在本机另存备份。

## 早期实验流程

```bash
python generate_data.py
python train.py
python evaluate.py
python baseline.py all
```

这组旧命令从`data/`读取输入，把权重写入`run/`、把图片与评估结果写入`out/`（`out/eval_results/`、`out/comparison/`、`out/pix2pix_compare/`）。路径约定见根目录`paths.py`。复现当前多菲涅耳数实验请使用[新入口](../fresnel_experiment/README.md)，并选择新输出目录。

旧生成器默认5000个256×256输入，八种几何策略，`APERTURE_NOISE=0.005`。加性扰动先施加到光阑，再由最终光阑计算标签；标签并未独立叠加观测噪声。整体乘性透过率缩放也不能直接等同于独立观测噪声。

旧标签和旧物理层共享：

```text
FFT → fftshift → |场|² → 峰值归一化 → log1p(100·I) → 再归一化
```

因此纯物理分支就能近乎复现标签；它首先检验仿真与实现一致性。

## 历史结果及当前解释

以下为旧验证集500个样本的记录（原始指标文件不随仓库发布）：

| 模型 | MAE | RMSE | PSNR | Corr |
|---|---:|---:|---:|---:|
| 纯物理 | 0.000000 | 0.000000 | 172.71 | 1.00000 |
| PureUNet基线 | 0.002694 | 0.024177 | 33.74 | 0.00572 |
| 物理＋残差 | 0.000000 | 0.000000 | 144.51 | 1.00000 |

表中零值是显示精度所致。物理分支已经接近标签，不能把整个优势计为残差网络的学习收益。近零分母下的百分比改善也不稳定。

旧实验的SSIM、学习率等配置不同；这些设置不能全部归因于模型结构。当前多NF实验对齐公共损失和主要训练配置，两种模型均默认关闭SSIM，只有残差模型使用残差正则。

自由残差会改变最终输出，固定物理分支并不保证最终图像非负、能量守恒或始终满足传播方程。旧文档中的这些保证应以当前解释为准。
